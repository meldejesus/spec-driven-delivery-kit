# Session Log

Running log of all work sessions. Newest first. Maintained by the `worklog` skill at session close.

Each entry is keyed by session timestamp, not by date — multiple sessions per day are distinct entries.

For the dashboard view of active tickets, see `worklog/dashboard.md`.
For full ticket history, see `workflow/<ticket-id>/handoff.md`.
